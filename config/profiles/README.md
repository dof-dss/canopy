# General profile examples

This directory contains illustrative, audit-pack-independent examples of the
capability-profile model. Profiles describe the reusable expectations for a
class of project rather than identifying concrete audit targets.

The files here are design examples and are not currently loaded directly by an
implemented audit pack. Operational profiles, including the detector metadata
required by their loaders, live under `config/editorial` and `config/assets`.

Concrete repository paths and target-specific expectations belong in the
consuming project's `.canopy/inventory.yml`.
